# Share Print

Share Print by AiBotCRM.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6ab9f7bb82e87a5f9475b070/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Share Print** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6ab9f7bb82e87a5f9475b070/releases/latest) and reinstall.
